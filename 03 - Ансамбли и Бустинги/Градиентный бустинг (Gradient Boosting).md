# 🚀 Градиентный бустинг (Gradient Boosting)

> [!abstract] Интуиция
> В отличие от [[Случайный лес (Random Forest)|Случайного леса]], где деревья обучаются параллельно и независимо, в **градиентном бустинге** модели строятся **последовательно**. Каждое следующее дерево обучается исправлять ошибки (остатки), допущенные суммой всех предыдущих деревьев.

---

## ⚙️ Механика алгоритма

1. Начинаем с базового константного предсказания $f_0(x) = \arg\min_c \sum L(y_i, c)$ (для MSE это просто среднее значение таргета $\bar{y}$).
2. Для каждой итерации $m = 1, \dots, M$:
   - Вычисляем псевдоостатки — антиградиент функции потерь для каждого объекта:
     $$r_{im} = -\left[ \frac{\partial L(y_i, f(x_i))}{\partial f(x_i)} \right]_{f = f_{m-1}}$$
     *(В случае MSE $L = \frac{1}{2}(y - f)^2$, антиградиент равен в точности остатку ошибки: $r = y - f(x)$)*.
   - Обучаем новое неглубокое дерево $b_m(x)$ предсказывать эти остатки $r_{im}$.
   - Обновляем суммарный ансамбль с темпом обучения (shrinkage) $\eta \in (0, 1]$:
     $$f_m(x) = f_{m-1}(x) + \eta \cdot b_m(x)$$

```mermaid

    X[Входные данные X] --> T1[Дерево 1: Базовый тренд]
    T1 --> R1[Остатки 1]
    R1 --> T2[Дерево 2: Исправление остатков]
    T2 --> R2[Остатки 2]
    R2 --> T3[Дерево 3: Тонкая доводка]

```

## 🆚 Сравнение: Бустинг vs Бэггинг

| Характеристика | Random Forest (Бэггинг) | Gradient Boosting |
| :--- | :--- | :--- |
| **Обучение** | Параллельное | Строго последовательное |
| **Базовые алгоритмы** | Глубокие деревья (Low bias, High variance) | Неглубокие деревья / пни (High bias, Low variance) |
| **Цель ансамбля** | Уменьшить дисперсию (разброс) | Уменьшить смещение (ошибку модели) |
| **Склонность к переобучению** | Низкая (число деревьев можно растить без страха) | Высокая (при избытке деревьев $M$ переобучится) |
| **Ключевой регулятор** | `max_depth`, `min_samples_split` | `learning_rate` ($\eta$), `n_estimators`, `subsample` |
