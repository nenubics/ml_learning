# 📈 Линейная регрессия (Linear Regression)

> [!abstract] Определение
> **Линейная регрессия** — базовый алгоритм обучения с учителем (Supervised Learning), прогнозирующий непрерывное числовое значение ($y$) как линейную комбинацию признаков ($x$) с весовыми коэффициентами ($w$).

---

## 📐 Математическая модель

Для объекта с признаками $\mathbf{x} = (x_1, x_2, \dots, x_d)$:

$$\hat{y} = w_0 + w_1 x_1 + w_2 x_2 + \dots + w_d x_d = \mathbf{w}^T \mathbf{x}$$

### Функция потерь: Mean Squared Error (MSE)

$$\text{MSE}(w) = \frac{1}{N} \sum_{i=1}^N \left( y_i - \hat{y}_i \right)^2 = \frac{1}{N} \| \mathbf{y} - \mathbf{X}\mathbf{w} \|_2^2$$

---

## 🔍 Способы нахождения оптимальных весов

1. **Аналитическое решение (Метод наименьших квадратов / Normal Equation)**:
   $$\mathbf{w}^* = (\mathbf{X}^T \mathbf{X})^{-1} \mathbf{X}^T \mathbf{y}$$
   - *Плюсы*: точное решение без итераций.
   - *Минусы*: обращение матрицы $\mathbf{X}^T \mathbf{X}$ имеет вычислительную сложность $O(d^3)$, невозможно при $d > 10^4$ признаков или при вырожденной (мультиколлинеарной) матрице.
2. **Численная оптимизация**:
   - Поиск решения через [[Градиентный спуск (Gradient Descent)]]. Масштабируется на миллионы признаков и строк.

---

## 🛡️ Регуляризация (Борьба с переобучением)

> [!tip] Зачем нужна регуляризация?
> Если признаки скоррелированы (мультиколлинеарность) или модель переобучается, веса $w$ могут принимать огромные значения. Регуляризация штрафует модель за слишком большие веса.

- **L2-регуляризация (Ridge / Гребневая регрессия)**:
  Штраф за сумму квадратов весов: $\text{Loss} = \text{MSE} + \alpha \sum w_j^2$. Сжимает веса к нулю, но не зануляет их полностью.
- **L1-регуляризация (Lasso)**:
  Штраф за сумму модулей весов: $\text{Loss} = \text{MSE} + \alpha \sum |w_j|$. Зануляет неинформативные веса (отбирает признаки).
- **ElasticNet**:
  Комбинация L1 и L2 штрафов.

---

## ⚖️ Плюсы и минусы

- ✅ Простая интерпретируемость (вес $w_j$ показывает вклад признака $x_j$).
- ✅ Быстрое обучение и легковесный инференс.
- ❌ Не способна напрямую улавливать сложные нелинейные зависимости без ручного создания признаков ([[Предобработка данных и Feature Engineering]]).
- ❌ Чувствительна к выбросам и разному масштабу данных.
